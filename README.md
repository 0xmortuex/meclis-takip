# Öğrenci Meclisi Takip

Okul öğrenci meclisi başkanı için söz, toplantı, karar, takvim ve fikir takip paneli.
Arka uç yok; tüm veriler tarayıcının localStorage alanında tutulur.

- **Yedek:** Üstteki "Yedekle" ile JSON indir, "Yükle" ile geri yükle. Tarayıcı verisi silinirse veriler gider.
- **Öğrenci görünümü:** "Öğrenci Görünümü" sekmesinden salt okunur HTML dosyası indirip paylaş.
- **Telefon:** Tarayıcı menüsünden "Ana ekrana ekle" ile uygulama gibi kur.
- Öğrenci kişisel verisi (ad vb.) girmeyin.
